## 1. 模块与依赖边界

```text
contracts/    观测、证据、计算、任务、结果、工具规格、结构化错误(纯 pydantic)
finance/      指标口径登记、实体登记、可比性校验、增长计算(纯 Python + Decimal)
retrieval/    CJK 二元组分词 + 关键词评分(M4 替换为 BM25 + 向量)
ports/        MetricSource / DocumentSource 接口
adapters/data fixture 实现(修订/时间边界语义集中在此)+ 三家样本
tools/        注册中心(schema 校验、预算、错误结构化)+ 五个工具
interfaces/   m1 CLI(工具脱离 Agent 单独调用)
bootstrap.py  装配:fixture → 工具注册表(M4 换真实数据源只改这里)
```

核心模块(contracts / finance / tools / retrieval / ports)不导入 deepagents /
langchain / langgraph;M0 的 m0 包保持原样,作为引擎实验记录保留。

## 2. 五个核心工具

| 工具 | 主版本 | 只读/幂等 | 说明 |
| --- | --- | --- | --- |
| `documents.search@1` | 1 | 是 | 先过滤(实体、版本可得性 ≤ as_of、时间范围)再评分;同文档多版本只检索截止时点最新版 |
| `documents.read@1` | 1 | 是 | 按证据 ID(chunk)或 版本+页/段落 定位读原文 |
| `finance.get_metrics@1` | 1 | 是 | 标准化观测查询;修订按 available_at ≤ as_of 取最新 |
| `finance.calculate_growth@1` | 1 | 是 | `(本期-同期)/同期`,公式版本 `growth.yoy@1`,记录输入 ID |
| `finance.compare_peers@1` | 1 | 是 | 同口径对齐;币种冲突整体报错,缺失逐行说明 |

## 3. 边界行为(M1 退出条件对照)

| 边界 | 行为 | 测试 |
| --- | --- | --- |
| 零分母 | value=None + `ZERO_DENOMINATOR`,不抛异常 | test_zero_denominator_* |
| 缺失值 | value=None(未披露)与 0(披露为零)分开表达;计算返回 `MISSING_INPUT`;同业表行级说明 | test_missing_input / test_missing_value_row |
| 币种冲突 | 增长计算 `INCOMPARABLE_INPUTS`;同业比较 `INCOMPARABLE_METRICS`(整体),给出"按币种分组"替代动作 | test_currency_conflict_* |
| 累计口径 | basis(cumulative/single_quarter)、scope(合并/母公司)、期间形状任一不同即不可比,列出差异项 | test_basis/scope/period_shape_conflict |
| 修订时间 | 修订版 available_at ≤ as_of 才可见;引用截止时间后的观测 ID → `DATA_NOT_FOUND` | test_revision_selected_by_as_of / test_unavailable_observation_id_rejected |
| 负基数 | 保留计算值 + `NEGATIVE_BASE` 解释限制 | test_negative_base_* |
| as_of 扩大 | 执行端拒绝,`INVALID_ARGUMENT` + detail `as_of_exceeds_task_cutoff`;收窄允许 | test_asof_cannot_exceed / test_narrower_asof_allowed |
