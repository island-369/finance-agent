## 2. 契约映射与已知降级(如实记录)

| 契约项 | 映射 | 说明 |
| --- | --- | --- |
| basis | 固定 cumulative | 业绩报表为年初至报告期末累计 |
| scope | 合并报表 | 上游口径 |
| available_at | 最新公告日期 | **时间精度为日**(§8.4 记录精度,不虚构时刻) |
| 修订版本链 | 无 | 上游只给"最新值+最新公告日期",无历史版本;fixture 的 v1/v2 修订链在真实源不可复现,revision_id 固定 `latest` |
| 数值精度 | Decimal(str(float)) | 上游即浮点,精度损失在数据源侧 |
| 文档检索 | 不覆盖 | akshare 无公告全文;documents.* 仍走 fixture,真实文档源留待后续 |

另:上游"最新公告日期"偶有晚于常规披露窗口的值(如 2025 年报显示 2026-04-17),
推断为补充/更正公告刷新,按上游原值记录,不自行修正。

## 3. 切换方式

```bash
# 默认 fixture(评测第一轮使用,固定数据快照 §16.2)
uv run m1 call finance.get_metrics '{...entity_id: demo-company-a...}'

# 真实源(仅财务观测;实体:cn-600519/cn-000858/cn-000568)
FINANCE_AGENT_DATA_SOURCE=akshare uv run m1 call finance.get_metrics \
  '{"entity_id":"cn-600519","metric":"net_profit","basis":"cumulative","period_start":"2026-04-01","period_end":"2026-06-30"}'
```

切换在 bootstrap 装配处(`FINANCE_AGENT_DATA_SOURCE`),工具与契约层零改动。
测试用注入 fetcher 的 FakeDF 覆盖映射/边界,不依赖网络。

## 4. 与评测的关系

(用例需人工标注真值,量级与成本另计)。
